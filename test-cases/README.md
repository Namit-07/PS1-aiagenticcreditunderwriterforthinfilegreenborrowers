# Underwriting scenario fixtures (SYNTHETIC)

Generated by `python sample-data/generate_sample_data.py`. Each JSON file is a ready-to-POST
`/underwrite` payload (`application` + inline `documents`) with the expected outcome, consumed
by `ai-service/tests/test_scenarios.py` and `backend/tests/test_underwriting.py`.

| Scenario | Expected | Reason codes | Notes |
|---|---|---|---|
| `clean_approval` | completed / **approved** | — | All four documents agree; FOIR/LTV inside policy; expect APPROVE. |
| `income_mismatch` | completed / **referred** | INCOME_MISMATCH | Declared income 45,000 vs bank credits 38,500 (13.5% gap) -> INCOME_MISMATCH -> REFER. |
| `high_foir` | completed / **declined** | HIGH_FOIR | Income 22,000, EMI obligations 6,000, loan 150,000 @16% for 24m -> FOIR > 0.50 -> REJECT. |
| `high_ltv` | completed / **declined** | HIGH_LTV | Loan 115,000 against a 120,000 vehicle -> LTV 0.96 > 0.80 -> REJECT. |
| `low_confidence` | awaiting_human / **human_review** | — | Bank statement scan is damaged (ocr_confidence 0.5, income line illegible) -> critical field below threshold -> workflow PAUSES for human review; after correction it completes with APPROVE. |
| `identity_mismatch` | completed / **referred** | NAME_MISMATCH | KYC name 'Ravi Kumaar' vs bank/invoice 'Ravi Kumar' -> NAME_MISMATCH -> REFER. |
| `missing_document` | completed / **referred** | MISSING_DOCUMENT | No dealer invoice uploaded -> MISSING_DOCUMENT -> REFER (curable by upload). |
| `what_if_approval` | completed / **declined** | HIGH_FOIR | Base run is the high_foir REJECT; what-if with tenure 48m lowers EMI so FOIR < 0.50 -> scenario APPROVE while the base run stays REJECT (immutable). |
| `low_age` | completed / **declined** | LOW_AGE | Borrower aged 19 with clean documents -> LOW_AGE blocker -> REJECT under default policy; APPROVE under the aggressive profile (min age 18). |

Decision matrix: any **blocker** reason → `declined`; any **warning** → `referred`; a critical field
below the policy confidence threshold pauses the run as `awaiting_human` (`human_review`).
